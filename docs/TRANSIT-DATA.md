# Ближайшие станции

`npm run transit:refresh` показывает diff без записи в Supabase; `npm run transit:refresh -- --apply` сохраняет backup и обновляет изменившиеся строки пакетами по 100 в одной транзакции. Затем `node --env-file-if-exists=.env.local scripts/sync-catalog.mjs` обновляет static snapshot. Независимо проверенные маршруты сохраняются.

Метро/МЦК: cached https://api.hh.ru/metro/1. МЦД: scripts/data/mcd-coordinates.json с URL конкретной станции и лицензией. Для обновления evidence сначала проверять действующий список линии и конкретный railway platform item, не одноимённую станцию метро. Закрытия имеют отдельные ссылки; не исключать станцию по старым планам переноса. Например, Москва-Товарная D2 продолжает рекомендоваться транспортным порталом, а Серп и Молот D4 временно закрыт.

Выбор — три ближайших различных названия в радиусе 5 км по haversine; при одинаковом названии сохраняется ближайшая платформа. Квоты по виду транспорта нет. Минуты: ceil(distance_meters * 1.3 / 80), всегда приблизительные, пока route_verified=false. Это не маршрутизация: забор, вход и переход через железную дорогу требуют отдельного подтверждения. Синхронизация обязана ставить walkEstimated=!route_verified независимо от домена источника. Не рассчитывать автомобильное время из расстояния по прямой.

6 октября 2026: изменены станции/оценки у 629 из 632 храмов с координатами; 588 изменили набор названий/линий. Покровское D2 у храма на Городне: 257 м между координатами, оценка ≈5 минут; сайт прихода подтверждает несколько минут пешком. 129 храмов без координат не пересчитываются. Повторный dry-run: 0 изменений. tests/transit.test.ts проверяет географию Покровского, независимость rail/metro и правильную дедупликацию.
